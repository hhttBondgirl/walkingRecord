# WalkingRecord
Laravelで作成した、ウォーキング記録管理アプリです。

## 作成した背景
お散歩が大好きで、毎日1時間半ほど歩いていた我が家の愛犬ハチが、パテラの状態が悪化したことで、一時期10分ほどしか歩けなくなってしまいました。

飼い主として「もう一度歩けるようになってほしい」「少しずつ自信を取り戻してほしい」という思いから、毎日どのくらい歩けたのかを記録することにしました。

毎日の散歩では常に携帯電話を持っていますが、ハチ以外にも2匹の犬と一緒に散歩しているため、ハチだけの歩行距離を正確に計測することは難しいと考えました。

そこで、歩いた「時間」を記録できることに加え、その日の健康状態や様子をメモとして残せるようにしたいと思い、このアプリを作成しました。

## 概要

WalkingRecordは、日々のウォーキング記録を登録・管理するためのWebアプリケーションです。

PHP / Laravelを使用して、記録の登録・表示・編集・削除といったCRUD機能を実装しています。

また、年月による検索、入力値のバリデーション、データベースのバックアップ、自動バックアップの仕組みなどを実装し、LaravelによるWebアプリケーション開発だけでなく、データ管理や運用面についても学習しました。

## 主な機能

- ウォーキング記録の登録
- ウォーキング記録の一覧表示
- ウォーキング記録の編集 (「年月」「朝/夕」「時間」「メモに入力したテキスト」など、複数の条件から絞り込んで過去の記録をサクッと探せます。)
- ウォーキング記録の削除
- 入力値のバリデーション
- 年月による記録検索
- MySQLによるデータ管理
- データベースのバックアップ
- シェルスクリプトによるバックアップ処理
- macOS launchdによる自動バックアップ

- CRUD機能
  - Create：記録の登録
  - Read：記録の一覧表示
  - Update：記録の編集
  - Delete：記録の削除

## 工夫したポイント

### バリデーション

フォームから入力されたデータに対してバリデーションを実装し、不正な値が登録されないようにしました。

### 年月検索

ウォーキング記録を年月単位で検索できる機能を実装しました。

### データベース

開発当初はLaravelのデフォルト設定であるSQLiteを使用していましたが、
今後のデータ増加や機能拡張を考慮し、開発途中でMySQLへ移行しました。
現在はMySQLを使用しています。

### エラー対応・デバッグ

実装中に発生したエラーについて、エラーメッセージやログ、データベースの状態などを確認しながら原因を切り分け、修正しました。

### セキュリティ確認

GitHubへの公開にあたり、環境変数やデータベースなどの機密情報が公開されないよう、公開用ファイルを確認しました。

## バックアップの自動化

データベースのバックアップ処理をShell Scriptとして作成し、macOSのlaunchdを利用して定期的に自動実行できる仕組みを構築しました。

### 使用したもの

- Shell Script
- UNIXコマンド
- macOS launchd

バックアップ処理を `backup_walkingRecord.sh` にまとめ、launchdから実行することで、手動でバックアップコマンドを実行しなくても定期的にデータを保存できるようにしました。

## セットアップ方法

### 1. リポジトリをクローン

```bash
git clone https://github.com/hhttBondgirl/walkingRecord.git
cd walkingRecord
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```

## GitHub公開版について

本リポジトリはポートフォリオとして公開するため、個人情報や認証情報などの機密情報を含まない公開用構成としています。

環境変数を管理する `.env` ファイルや、GitHubへ公開する必要のないファイルはリポジトリに含めないよう設定しています。

また、バックアップ処理に使用するファイルについても、個人環境に依存する情報を確認・整理した上で公開しています。
