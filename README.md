# WalkingRecord
Laravelで作成した、ウォーキング記録管理アプリです。

## 概要

WalkingRecordは、日々のウォーキング記録を登録・管理するためのWebアプリケーションです。

PHP / Laravelを使用して、記録の登録・表示・編集・削除といったCRUD機能を実装しています。

また、年月による検索、入力値のバリデーション、データベースのバックアップ、自動バックアップの仕組みなどを実装し、LaravelによるWebアプリケーション開発だけでなく、データ管理や運用面についても学習しました。

## 主な機能

- ウォーキング記録の登録
- ウォーキング記録の一覧表示
- ウォーキング記録の編集
- ウォーキング記録の削除
- 入力値のバリデーション
- 年月による記録検索
- MySQL / SQLiteによるデータ管理
- データベースのバックアップ
- シェルスクリプトによるバックアップ処理
- macOS launchdによる自動バックアップ

- CRUD機能
  - Create：記録の登録
  - Read：記録の一覧表示
  - Update：記録の編集
  - Delete：記録の削除

## 工夫したポイント

### バリデーション

フォームから入力されたデータに対してバリデーションを実装し、不正な値が登録されないようにしました。

### 年月検索

ウォーキング記録を年月単位で検索できる機能を実装しました。

### データベース

開発環境ではMySQLを使用し、SQLiteについても動作確認を行いました。

### エラー対応・デバッグ

実装中に発生したエラーについて、エラーメッセージやログ、データベースの状態などを確認しながら原因を切り分け、修正しました。

### セキュリティ確認

GitHubへの公開にあたり、環境変数やデータベースなどの機密情報が公開されないよう、公開用ファイルを確認しました。

## バックアップの自動化

データベースのバックアップ処理をShell Scriptとして作成し、macOSのlaunchdを利用して定期的に自動実行できる仕組みを構築しました。

### 使用したもの

- Shell Script
- UNIXコマンド
- macOS launchd

バックアップ処理を `backup_walkingRecord.sh` にまとめ、launchdから実行することで、手動でバックアップコマンドを実行しなくても定期的にデータを保存できるようにしました。
